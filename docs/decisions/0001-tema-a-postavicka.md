# ADR 0001: Téma a postavička

- Stav: prijaté (2026-11-03)

## Kontext
Treba určiť prostredie a hráča, aby sa dalo plánovať pozadie, paleta a assety.

## Rozhodnutie
- Téma: **les / príroda**.
- Hráč: **malé zvieratko (líška alebo mačka)**.

## Dôsledky
- Parallax: obloha → ďaleké hory → les → stromy → popredie (4–5 vrstiev).
- Jednoduchá silueta postavy, dobre čitateľná na pozadí; veľa CC0 assetov pre lesné tilesety.
- Konkrétny druh (líška vs. mačka) sa určí pri výbere asset packu.
